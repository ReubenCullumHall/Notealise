Opening Notealise for the first time

Notealise for Linux is a single file, Notealise.AppImage. There is nothing to install: you let the file run as a program, then open it.

Linux asks this of every program downloaded as a single file, not just this one. The full source is on GitHub.

Ready to download Notealise for Linux. Download it

  1. Put it somewhere to keep

    Move Notealise.AppImage out of your Downloads folder into one you will not tidy away — a folder called Applications in your Home folder is a good place. Updates replace this file wherever it is. Your notes are never inside it.

  2. Let it run as a program

    Right-click Notealise.AppImage and choose Properties. Turn on Executable as Program. On some systems it is a tick box on the Permissions tab instead, called Allow executing file as program or Is executable.

  3. Open it

    Double-click Notealise.AppImage. Notealise opens. From now on, that same file is the app: double-click it whenever you want to write.

Not opening?

Some file managers will not start a program on a double-click. Open it from a Terminal instead:

  1. Right-click the folder Notealise.AppImage is in and choose Open in Terminal.
  2. Type chmod +x Notealise.AppImage and press Enter. This does the same as step 2.
  3. Type ./Notealise.AppImage and press Enter.

If the Terminal then mentions FUSE, your system is missing a small part Notealise needs to open. Install the package called fuse3 from your software centre (on Ubuntu, type sudo apt install fuse3), then try again.
