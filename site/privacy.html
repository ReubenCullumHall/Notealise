Privacy

Privacy

Notealise runs on your computer and keeps your notes as plain files on your own disk. It has no account system, no analytics, and no way to send your notes anywhere.

Last updated 4 September 2026

In short

  • Your notes never leave your computer. Notealise reads and writes plain Markdown files in a folder you choose, and has no server to send them to.
  • There is no account, no sign-in, no analytics, no tracking, and no advertising.
  • The app makes a small, fixed set of outbound connections, all listed below: a version check, and — only if you ask for one — a font download.
  • Because no personal information is collected, there is nothing to sign in to, export, or delete.

Who runs Notealise

Notealise is made and run by Reuben Cullum Hall, a sole trader based in the United Kingdom (“Notealise”). For any question about this policy, or about privacy and data protection, write to legal@notealise.com. For UK data-protection purposes, that is also the contact for the data controller.

What stays on your computer

Everything you create in Notealise stays on your machine:

  • Your notes, as .md files in the folder (“vault”) you pick.
  • App settings — theme, layout, spaces, pins and the rest — in a hidden .mdnotes folder inside that vault.
  • A little install-level state (which folder is your vault, and your update preference) in your operating system’s standard per-application data folder.

None of this is transmitted anywhere. Delete Notealise and all of it stays exactly where it is, readable in any other Markdown editor.

What the app connects to

Notealise is offline-first. It opens an outbound network connection only in these cases:

  • Checking for a new version. Shortly after launch and a few times a day, Notealise asks GitHub — where its releases are published — whether a newer version exists. Like any web request, this tells GitHub that the request came from your device’s IP address, along with a short string naming the app version and your operating system. Notealise does not receive, see, or store any of that. The check currently cannot be turned off, because a silently out-of-date install is the problem it exists to prevent. What GitHub does with the request is covered by the GitHub Privacy Statement.
  • Downloading an optional font. Notealise ships with several typefaces built in. If, and only if, you choose to download one of the extra fonts from the font picker, the app fetches that single font file from the jsDelivr CDN (cdn.jsdelivr.net). Nothing is fetched unless you ask for a specific font.
  • Installing an update. If you choose to install an update, the app downloads the new version from GitHub.
  • Opening a link. Clicking a link in a note hands it to your normal web browser. From there you are browsing the web as usual, outside Notealise.

That is the whole list. There is no background sync, no telemetry, no crash reporting, and no other phone-home.

Email

The in-app bug-report and feature-request forms do not send anything by themselves. They open a pre-filled draft in your own mail app, which you then send — no note content and no machine details are attached. If you email a Notealise address, that message reaches an ordinary mailbox and is kept only as long as needed to deal with it. Please don’t include anything sensitive that isn’t needed.

The website

This site (notealise.com) is a set of static pages hosted by Vercel. It runs no analytics scripts and sets no tracking cookies. As the host, Vercel keeps standard server access logs, including visitor IP addresses, for security and operational reasons — see the Vercel Privacy Notice. The download buttons link to the release files on GitHub, so using one sends a request to GitHub. If analytics are ever added to this site, this page will say what and why first.

Your rights

Notealise does not collect or process personal data about you, so rights such as access, correction, erasure and portability have nothing to act on. If you are in the UK or the EU and think that is wrong in some specific case, write to legal@notealise.com and it will be looked into. You also have the right to complain to the Information Commissioner’s Office (ico.org.uk).

Children

Notealise is a general-purpose writing tool, not aimed at children, and collects no information from anyone.

Changes
