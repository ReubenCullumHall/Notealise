First launch: getting past the "unverified developer" warning

This MVP build is unsigned, so your OS will warn you the first time. It's safe to open:

Windows — on the blue "Windows protected your PC" screen, click More info → Run anyway.

macOS — after dragging Notealise to Applications, right-click the app → Open, then confirm. (If it says the app is "damaged", open Terminal and run xattr -cr /Applications/Notealise.app, then open it.)
