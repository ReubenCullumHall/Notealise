Known problems, left visible

  • Fix in buildThe selection colour comes from the accent colour. With the default accent it's grey, so a selection is a grey wash. With a coloured accent it will be that colour.
  • New iconThe app has no scissors icon yet. This one is drawn to match the others (same line weight), but it's new.
  • Not shownThe opening and closing motion: the plan is Settings' own open and close. Hover states and Windows text haven't been checked either.
